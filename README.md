# Chengyu Miao — Academic Homepage

Personal academic homepage for **Chengyu Miao**, hosted with GitHub Pages.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

## Structure

- `index.html` — page content
- `style.css` — responsive visual design
- `script.js` — theme toggle and small UI behavior

The site intentionally uses no build step or framework, so updates remain simple.
